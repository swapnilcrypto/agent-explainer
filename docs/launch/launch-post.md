# Launch post draft

I built Agent Explainer: a small interactive lab for understanding how AI agents work—and why they fail.

Try three experiments:

- Lose a tool response and watch a retry create a duplicate ticket.
- Compress a conversation and see a draft-only instruction disappear.
- Let an agent say “done” before its report actually exists.

Then change one mechanism and replay the same case. You can inspect what the agent knows, what the tool returned, and what is actually true in the simulated world.

No account, API key, or model bill. These are clearly labeled, deterministic teaching simulations—not claims about a model's hidden reasoning or benchmark performance.

Try it: https://swapnilcrypto.github.io/agent-explainer/
Source: https://github.com/swapnilcrypto/agent-explainer

It is in public beta. I would love feedback on which explanation is confusing and which failure deserves the next experiment. Contributions are welcome.
