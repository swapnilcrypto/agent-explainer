# Approved product brief

Agent Explainer is an open-source interactive science lab for developers learning agentic systems. The authorizing owner is the repository maintainer; visitors use it free of charge.

The job: understand a failure mechanism by running a small experiment, inspecting evidence, changing one repair, and comparing the result. The differentiator is a coherent, accessible cause-and-effect experience with independent world-state verification.

Launch includes duplicate-action, forgotten-instruction, and premature-done simulations; timeline inspection; repaired replays; comparisons; versioned sharing; local progress; light/dark themes; glossary; sources; and contribution support.

No live model, real tool action, account, database, user-data upload, telemetry, multiplayer, or monetization belongs in this release. Continuous batching is post-launch. The existing lifecycle field guide stays separate.

The primary user is a developer learning agents. Educators, technical writers, and experienced engineers explaining incidents are supporting users. The application is a static React/TypeScript/Vite site hosted on GitHub Pages.

Quality target: at least eight of ten pilot participants complete an experiment unaided and correctly explain the repair. Community ambition: work toward 1,000 genuine GitHub stars without forecasting a result. Beta availability does not imply the pilot or stable release gate has passed.

See architecture, verification, and release documentation for implementation evidence and constraints.
