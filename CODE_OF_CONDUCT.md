# Community code of conduct

Treat learners and contributors with patience and respect. Welcome questions, credit others' work, and criticize ideas rather than people.

Harassment, discrimination, threats, sexualized content directed at participants, doxxing, and repeated disruptive behavior are not acceptable. Never post another person's private information or private agent transcripts.

Maintainers may edit or remove inappropriate content, warn participants, restrict participation, or ban repeat or severe offenders. Decisions should be proportionate and explain the applicable behavior without exposing private reports.

For public misconduct, use GitHub's report-content tools and alert the repository maintainer when safe. Use GitHub's private abuse-reporting channels for harassment or threats; do not create a public issue containing sensitive evidence. Maintainers are held to the same standards.

These expectations apply to this repository's issues, pull requests, discussions, and project events.
